# HTML
Markup language that structures web pages.  
Lenguaje de marcado que estructura las páginas web.

## 01-document
Defines basic structure of an HTML5 document.  
Define la estructura básica de un documento HTML5.

## 02-text
Tags for displaying and formatting text.  
Etiquetas para mostrar y dar formato al texto.

## 03-anchor
Links to other pages or resources.  
Enlaza a otras páginas o recursos.

## 04-script
Inserts JavaScript code.  
Inserta código en JavaScript.

## 05-link
Inserts external CSS stylesheets.  
Inserta hojas de estilo CSS externas.

## 07-lists
Creates ordered and unordered lists.  
Crea listas ordenadas y desordenadas.

## 08-images
Inserts an image.  
Inserta una imagen.

## 09-tables
Creates tables for data display.  
Crea tablas para mostrar datos.

## 10-challenge-tables
Practices table creation and structure.  
Practica la creación y estructura de tablas.

## 11-forms
Creates interactive forms for user input.  
Crea formularios interactivos para entradas de usuario.

## 12-graphics
Creates inline graphics with tags.  
Crea gráficos en línea con etiquetas.

## 13-audio
Inserts audio files.  
Inserta archivos de audio.

## 14-video
Inserts video files.  
Inserta archivos de video.

## 15-structure
Defines layout with non-semantic tags (old style).  
Define la estructura con etiquetas no semánticas (estilo antiguo).

## 16-semantic
Defines layout with semantic tags (new style).  
Define la estructura con etiquetas semánticas (estilo nuevo).
